## 🚀 Sobre mim

**Desenvolvedor Full-Stack** dinâmico trabalhando em todo o ciclo de vida do desenvolvimento de aplicações, utilizando um ecossistema focado em **Python**, **FastAPI**, **React** e **TypeScript**.

Tenho experiência de ponta a ponta no desenvolvimento de robustos sistemas corporativos e comerciais, desde regras de negócios complexas até a renderização no front-end, incluindo gestão otimizada de ambientes com Docker e gerenciamento de dados com PostgreSQL de forma assíncrona.

### 🏗️ Arquitetura, Ferramentas & Princípios
`Clean Code` • `APIs RESTful` • `Python Asynchronous Pattern` • `SPA (Single Page Application)` • `Containerização` • `Test-Driven Development (Pytest)`

### ⚡ Diferenciais Técnicos
- Arquitetura de aplicações assíncronas em Python com **FastAPI** e **SQLAlchemy Async**
- Criação de interfaces web ágeis utilizando **React** impulsionado por **Vite**
- Infraestrutura completa mantida com **Docker** e **Docker Compose**
- Regras de negócios complexas como composição de produtos e conversões de unidades de estoque mapeadas e automatizadas em um backend robusto
- Criação de scripts automatizados de build e testagem em ambiente Windows (Powershell)
